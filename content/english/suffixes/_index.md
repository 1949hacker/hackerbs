# 常见后缀

后缀不改变词根核心含义，只决定**词性**（名词/动词/形容词/副词）。学透后缀 = 看到一个词就能判断它在句子中的角色。

## 名词后缀

### 动作/过程/结果 → -tion 族

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-tion** / **-sion** | 动作、状态、结果 | education, production, reduction, discussion, decision |
| **-ation** | 动作、过程 | information, application, transformation |
| **-ition** | 动作、状态 | addition, competition, definition |
| **-ution** | 动作、结果 | solution, revolution, evolution |

### 动作/过程 → -ment / -al 族

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-ment** | 动作、结果、手段 | development, agreement, environment, achievement |
| **-al** | 动作、过程 | arrival, approval, proposal, survival |
| **-age** | 动作、结果、集合 | passage, marriage, percentage, storage |

### 状态/性质 → -ce / -cy / -ity 族

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-ance** / **-ence** | 状态、性质 | importance, appearance, difference, evidence |
| **-cy** | 状态、性质 | accuracy, efficiency, frequency, privacy |
| **-ity** / **-ty** | 性质、状态 | ability, quality, reality, capacity, safety |
| **-ness** | 状态、性质 | awareness, happiness, weakness, darkness |
| **-hood** | 状态、身份 | childhood, neighbourhood, likelihood |
| **-ship** | 状态、关系、技能 | relationship, leadership, friendship, scholarship |

### 人/做动作的人 → -er / -or / -ist 族

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-er** / **-or** | 做…的人/物 | teacher, worker, computer / actor, director, conductor |
| **-ist** | …主义者/…家 | scientist, artist, economist, psychologist |
| **-ant** / **-ent** | 做…的人/物 | applicant, assistant / student, president |
| **-ee** | 被…的人 | employee, trainee, refugee, interviewee |
| **-ian** | …的人/专家 | musician, politician, technician, librarian |

## 动词后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-ate** | 使成为、做 | create, indicate, communicate, demonstrate |
| **-ify** / **-fy** | 使…化 | identify, specify, clarify, simplify, modify |
| **-ise** / **-ize** | 使…化 | realise, recognise, organise, modernise |
| **-en** | 使变成 | strengthen, weaken, broaden, shorten |

## 形容词后缀

### 能力/倾向

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-able** / **-ible** | 可…的、能…的 | capable, portable, acceptable, possible, visible |
| **-ive** | 有…倾向的 | active, creative, effective, attractive, productive |
| **-ous** | 充满…的 | famous, dangerous, various, obvious, precious |

### 关联/属性

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-al** / **-ial** | …的、关于…的 | national, natural, personal, financial, industrial |
| **-ic** | …的 | economic, scientific, specific, academic, dramatic |
| **-ful** | 充满…的 | useful, helpful, powerful, successful, careful |
| **-less** | 没有…的 | homeless, endless, useless, harmless, careless |
| **-y** | 有…特征的 | healthy, wealthy, rainy, risky, lengthy |
| **-ent** / **-ant** | …的 | different, independent, confident / important, significant |
| **-ary** / **-ory** | 与…有关的 | necessary, primary, ordinary / satisfactory, compulsory |

## 副词后缀

| 后缀 | 含义 | 示例 |
|------|------|------|
| **-ly** | 以…方式 | quickly, carefully, significantly, approximately |

## 后缀叠加规律

一个词可以叠加多个后缀，每个后缀加一层词性：

```
educate  →  educat(e) + -ion = education  (动词 → 名词)
         →  education + -al = educational (名词 → 形容词)
         →  educational + -ly = educationally (形容词 → 副词)

produce  →  product + -ive = productive (名词 → 形容词)
         →  productive + -ity = productivity (形容词 → 名词)
```

这就是为什么掌握后缀后，一词多性不再是负担，而是同一家族的不同成员。

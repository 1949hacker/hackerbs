# 英语词根词缀学习系统

> 这是作者的个人词根笔记本，公开存放。内容按词根词缀法组织，目标是 **认识一个词根，推出一串单词**，辅助雅思 7.0 备考。不属于完整的英语课程，而是作者边学边建的知识系统。欢迎读者参考，但结构以作者的个人学习路径为准。

用词根词缀法拆解英语词汇，把孤立的单词串联成语义网络。

## 为什么用词根词缀

- 一个词根往往衍生 5–20 个单词，记住词根比死记硬背每一个单词高效
- 词根之间的关系（同源、反义、派生）天然适合用知识图谱表达
- 遇到生词时，拆解前缀 + 词根 + 后缀就能猜出大意

## 体系入口

- [[english/roots/_index|词根库]] — 按词根字母序排列，每个词根下面挂派生词
- [[english/prefixes/_index|前缀库]] — 常见前缀（pre-, re-, dis-, un- ...）
- [[english/suffixes/_index|后缀库]] — 常见后缀（-tion, -able, -ous ...）
- [[english/word-families/_index|词族地图]] — 把同源词根串联成大族谱（如 PIE *gene- → gen, nat, gno）

## 建议学习路线

1. 先过一遍 [[english/prefixes/_index|前缀库]]，掌握方向性前缀（pre- 前, re- 回/再, ex- 出, in- 入/不）
2. 进入 [[english/roots/_index|词根库]]，每天 1–2 个词根，顺着派生词链条记单词
3. 遇到感兴趣的大族谱，跳进 [[english/word-families/_index|词族地图]] 看全景
4. 学完一批词根后，用 [[english/exercises/_index|练习与自测]] 巩固

## 笔记规范

每篇词根笔记遵循统一结构，以 [[english/roots/preci|preci]] 为例：

> **词根** → **含义** → **派生词列表**（含拆解和字面义/实际义） → **反义词 / 易混辨析** → **相关词根** → **图谱链接**

这样每篇笔记既是学习单元，也是图谱中的一个节点。

# duc / duct — 引导、带领

## 核心含义

拉丁语 _ducere_ = to lead, to guide。这个根在 IELTS 写作中极其有用——几乎所有的因果论证都离不开它的派生词。

两种形态：
- **duce** — 动词结尾（produce, reduce, introduce）
- **duct** — 名词/形容词（product, conduct, productive）

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **produce** | pro-(前) + duce(引导) | 引导出来 | 生产、产生 |
| **reduce** | re-(回) + duce(引导) | 引导回去 → 缩减 | 减少、降低 |
| **introduce** | intro-(入) + duce(引导) | 引导进入 | 介绍、引入 |
| **conduct** | con-(一起) + duct(引导) | 引导到一起 | 进行、实施、行为 |
| **product** | pro-(前) + duct(引导出之物) | 引导出来的东西 | 产品、产物 |
| **education** | e-(=ex,出) + duc(引导) + -ation | 引导出来 → 启发 | 教育 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **deduce** | de-(向下) + duce(引导) | 往下推导 | 推论、演绎 |
| **induce** | in-(入) + duce(引导) | 引导进入 → 诱使 | 引起、诱导 |
| **productive** | product + -ive(形容词) | 能产出的 | 富有成效的 |
| **reduction** | reduce + -tion | 减少的行为/结果 | 减少、缩减 |
| **introduction** | introduce + -tion | 引入的行为 | 介绍、引言 |
| **conductor** | conduct + -or(人/物) | 引导者 | 指挥、导体 |

## 例句（IELTS 场景）

- **produce** — *The factory produces over 10,000 units per month.*
  - 写作 Task 1 描述产量：produce / production / productivity
- **reduce** — *Governments must take measures to reduce carbon emissions.*
  - 写作 Task 2 最高频动词之一：reduce pollution / costs / inequality
- **introduce** — *The university plans to introduce a new curriculum next year.*
  - 写作/口语讨论改革：introduce a policy / legislation / measure
- **conduct** — *The research was conducted over a five-year period.*
  - 写作/阅读描述研究：conduct an experiment / survey / investigation
- **product** — *Gross Domestic Product (GDP) measures a country's economic output.*
  - 阅读/写作经济话题核心术语
- **education** — *Access to quality education remains a global challenge.*
  - 写作 Task 2 最高频话题词之一
- **deduce** — *From the data, we can deduce that consumer preferences are shifting.*
  - 写作 Task 1 结论段：it can be deduced that...

## 前缀拆解公式

```
[方向前缀] + duc/duct

pro-   前   + duce → produce     生产（向前引出）
re-    回   + duce → reduce      减少（往回引）
intro- 入   + duce → introduce   介绍（引入）
con-   一起 + duct → conduct     进行（引导到一起）
e-     出   + duc  → educate     教育（把潜能引导出来）
de-    向下 + duce → deduce      推论（向下推导得出）
in-    入   + duce → induce      引起（引入）
```

## 易混辨析

- **produce** vs **product** vs **production**：produce (v.) / product (n. 产品) / production (n. 生产过程)
- **conduct** 做名词 vs 动词：名词读 /ˈkɒndʌkt/（行为），动词读 /kənˈdʌkt/（实施）— IELTS 听力重音变化是考点
- **deduce** vs **induce**：deduce 是从一般到具体（演绎），induce 是从具体到一般（归纳）— 阅读 Section 3 逻辑题关键

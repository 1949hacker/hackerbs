# cre / creat — 创造、生长

## 核心含义

拉丁语 *creare* = to create, to produce, to bring forth。所有派生词都围绕"让某物产生或生长"展开。

## 派生词网络

### Tier 1 — 雅思高频核心

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **create** | cre(创造) + -ate(动词) | 创造出来 | 创造、产生、引起 |
| **creative** | create + -ive | 善于创造的 | 有创意的、创造性的 |
| **creature** | creat(创造) + -ure | 被创造之物 | 生物、动物 |
| **increase** | in-(向上/内) + cre(生长) + -ase | 不断生长 | 增加、增长 |
| **decrease** | de-(向下) + cre(生长) + -ase | 向下减少 | 减少、降低 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **creation** | create + -ion | 创造的过程/产物 | 创造、作品 |
| **creativity** | creative + -ity | 创造力 | 创意、创造性 |
| **recreation** | re-(再) + create + -ion | 重新创造精力 | 娱乐、休闲 |
| **crescent** | cresc(生长) + -ent | 在生长的 | 新月形（的） |
| **concrete** | con-(一起) + crete(生长) | 生长到一起 | 具体的、混凝土 |

## 例句（IELTS 场景）

- **create** — *Technology has created new opportunities for remote learning.*
  - 写作 Task 2 万能动词：create jobs / problems / opportunities
- **creative** — *Creative thinking is essential for problem-solving in any field.*
  - 写作/口语高频：creative thinking / a creative solution
- **increase** — *The population has increased significantly over the past decade.*
  - 写作 Task 1 描述趋势核心词
- **decrease** — *The number of participants decreased sharply in 2023.*
  - 写作 Task 1：a decrease of / decrease by / decrease to
- **recreation** — *Parks provide opportunities for recreation and relaxation.*
  - 写作城市/环境话题：recreational facilities / areas

## 前缀拆解公式

```
[前缀] + cre/creat

in- 内/向上 + crease → increase  增长（不断生长）
de- 向下   + crease → decrease  减少（向下减少）
re- 再     + create → recreate  再造 → 消遣
con- 一起  + crete → concrete  凝结在一起 → 具体的
```

## 易混辨析

- **increase** vs **grow**：increase 是定量增长（数字/比率），grow 更通用（植物/能力/经济）
- **create** vs **invent**：create 创造（偏艺术/创意/问题），invent 发明（偏技术/器械）
- **recreation** vs **entertainment**：recreation = 消遣活动（积极休闲），entertainment = 娱乐（被动观看）
- **concrete** vs **specific**：concrete = 可感知的/具体的（concrete evidence），specific = 明确的/特定的（specific details）

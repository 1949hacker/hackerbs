# proper / propri — 自己的、合适的

## 核心含义

拉丁语 _proprius_ = one's own, special, particular。「自己的」→ 引申为「本来的、特有的」→ 再引申为「合适的」。

三条语义路径：

1. **"自己的 → 所有权"** → property, proprietor
2. **"自己的 → 合适的"** → proper, properness
3. **"使成为自己的 → 占用/适应"** → appropriate

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **proper** | proper ← proprius | 自己的 → 本来的 | 合适的、正确的、严格意义上的 |
| **property** | proper + -ty(名词) | 属于自己的东西 | 财产、特性、属性 |
| **appropriate** (adj.) | ap-(向) + propri(自己) + -ate | 成为自己的 | 合适的、恰当的 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **appropriate** (v.) | 同上 | 使成为自己的 | 占用、挪用、拨（款） |
| **inappropriate** | in-(不) + appropriate | 不合适的 | 不恰当的、不得体的 |
| **proprietor** | propri(自己) + -etor(人) | 拥有自己的人 | 所有者、业主 |
| **improper** | im-(不) + proper | 不合适的 | 不适当的、不得体的 |

## 例句（IELTS 场景）

- **proper** — *Without proper nutrition, children's physical and cognitive development may be impaired.*
  - 写作 Task 2 健康/教育话题：proper + noun（proper training / management / planning）
- **property** — *Intellectual property rights protect the work of creators and innovators.*
  - 阅读/写作法律话题：intellectual property, physical properties
  - 注意义项切换：「财产」和「属性」是同一个词
- **appropriate** — *It is not appropriate for young children to have unsupervised access to social media.*
  - 写作 Task 2 万能判断词：it is appropriate to / an appropriate measure
- **inappropriate** — *The advertisement was criticized for its inappropriate content.*
  - 写作/口语表达否定判断
- **appropriate** (v.) — *The government has appropriated significant funds for infrastructure development.*
  - 阅读 Section 3 经济/政策话题

## 常见搭配速记

| 搭配 | 含义 | 场景 |
|------|------|------|
| proper + noun | 适当的… | 写作万能修饰 |
| in the proper sense | 在严格意义上 | 写作限定范围 |
| intellectual property | 知识产权 | 阅读/写作法律话题 |
| physical / chemical properties | 物理/化学特性 | 阅读科学话题 |

| highly / entirely appropriate | 非常合适 | 写作/口语 |

## 前缀拆解公式

```
[前缀] + propri/proper

ap-   向  + propri → appropriate   使成为自己的 → 占用 / 合适的
in-   不  + appropriate → inappropriate  不合适的
im-   不  + proper → improper     不适当的
```

## 同词根但被隐藏的词

- **proprietary** — propri(自己) + -etary → 专有的、所有权的（proprietary software 专有软件）
- **expropriate** — ex-(出) + propri(自己) + -ate → 使脱离所有权 → 征用、没收

## 易混辨析

- **proper** vs **appropriate**：proper 强调"对/错了"（proper procedure），appropriate 强调"合适/不合适"（appropriate behavior）。两者常可互换，但 proper 更偏向"正确性"，appropriate 更偏向"得体性"。
- **property**（财产）vs **property**（属性）：同一个词，根据上下文判断。听力中如果讨论房地产（real estate property）和科学实验（chemical properties），词义完全不同。
- **appropriate** 做形容词 vs 动词：形容词读 /əˈprəʊpriət/，动词读 /əˈprəʊprieɪt/ — 末尾音节不同，听力考点。

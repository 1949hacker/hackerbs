# ven / vent — 来、到来

## 核心含义

拉丁语 _venire_ = to come。这个根在英语中沿着三条路径展开：

1. **"来 → 到来/发生"** → event, eventually, adventure
2. **"来 → 来到一起/交汇"** → convenient, convention, revenue
3. **"来 → 在之前/之间来"** → prevent, intervene, invent

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **event** | e-(=ex,出) + vent(来) | 出来的事 | 事件、活动 |
| **prevent** | pre-(前) + vent(来) | 提前来拦住 | 阻止、预防 |
| **invent** | in-(入) + vent(来) | 来到脑海里 | 发明、创造 |
| **convenient** | con-(一起) + ven(来) + -ient | 大家一起来 | 方便的、便利的 |
| **convention** | con-(一起) + vent(来) + -ion | 一起来的地方/规矩 | 大会、惯例、公约 |
| **revenue** | re-(回) + ven(来) + -ue | 收回来的东西 | 收入、税收 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **eventually** | event + -ual + -ly | 事情最终发生 | 最终、终于 |
| **adventure** | ad-(向) + vent(来) + -ure | 走向未知 | 冒险、奇遇 |
| **intervene** | inter-(之间) + ven(来) + -e | 来到中间 | 干预、介入 |
| **conventional** | convention + -al | 惯例的 | 常规的、传统的 |
| **inventor** | invent + -or(人) | 发明的人 | 发明家 |
| **prevention** | prevent + -ion | 阻止的行为 | 预防、防止 |
| **avenue** | a-(=ad,向) + venue(来) | 来的路 | 大街、途径 |

## 例句（IELTS 场景）

- **event** — *Major sporting events can boost the local economy significantly.*
  - 听力/口语：in the event of / a significant event
- **prevent** — *Vaccination is the most effective way to prevent the spread of infectious diseases.*
  - 写作 Task 2 健康话题：prevent ... from happening
- **invent** — *The internet was invented in the late 20th century and has since transformed society.*
  - 口语 Part 3 讨论科技：invent / invention / innovative
- **convenient** — *Online shopping is convenient, but it has led to the decline of local businesses.*
  - 写作 Task 2 讨论利弊：it is convenient to / for convenience
- **convention** — *Social conventions vary significantly across cultures.*
  - 写作/口语：social convention / by convention / international convention
- **revenue** — *Tax revenue is the primary source of government funding for public services.*
  - 写作 Task 2 经济话题：generate revenue / annual revenue
- **eventually** — *If left unchecked, the problem will eventually affect the entire ecosystem.*
  - 写作描述长期后果
- **intervene** — *The government should intervene when market forces fail to protect public interests.*
  - 写作 Task 2 政府角色类话题
- **conventional** — *Conventional farming methods are being replaced by more sustainable practices.*
  - 写作对比新旧：conventional approach / conventional wisdom

## 前缀拆解公式

```
[前缀] + ven/vent

con-  一起 + ven → convenient   方便的（一起来）
con-  一起 + vent → convention  大会/惯例（聚到一起的）
e-    出   + vent → event       事件（出来的事）
pre-  前   + vent → prevent     阻止（提前来拦住）
in-   入   + vent → invent      发明（来到脑海里）
re-   回   + ven  → revenue     收入（收回来的钱）
ad-   向   + vent → adventure   冒险（走向未知）
inter-之间 + ven  → intervene    干预（来到中间）
```

## 易混辨析

- **event** vs **incident**：event 是大事（中性/正面），incident 是小事/事故（负面）
- **invent** vs **discover**：invent 是创造不存在的东西，discover 是发现已存在的东西
- **convenient** vs **comfortable**：convenient = 省时省力（强调效率），comfortable = 身体舒服（强调感觉）
- **revenue** vs **income**：revenue 是机构/公司的总收入，income 是个人收入

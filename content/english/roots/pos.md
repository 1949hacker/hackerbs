# pos / pon / pose — 放、放置

## 核心含义

拉丁语 *ponere* = to put, to place, to set。这是英语中派生词最多的词根之一——前缀决定"怎么放"，pose 决定"放"本身。

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **position** | pos(放) + -ition(名词) | 放置的位置 | 位置、职位、立场 |
| **purpose** | pro-(前→古法语) + pos(放) | 放在前面的东西 | 目的、意图 |
| **propose** | pro-(前) + pose(放) | 放在前面 | 提议、建议、求婚 |
| **oppose** | op-(=ob,反) + pose(放) | 反着放 | 反对、对抗 |
| **compose** | com-(一起) + pose(放) | 放到一起 | 组成、创作（音乐/文字） |
| **expose** | ex-(出) + pose(放) | 放出去 | 暴露、揭露、接触 |
| **impose** | im-(=in,上) + pose(放) | 放在上面 | 强加、征收（税） |
| **suppose** | sup-(=sub,下) + pose(放) | 放在下面(作为前提) | 假设、认为 |
| **deposit** | de-(下) + posit(放) | 放下来 | 存放、存款、押金 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **dispose** | dis-(分开) + pose(放) | 分开摆放 | 处理、处置、使倾向于 |
| **postpone** | post-(后) + pone(放) | 放到后面 | 推迟、延期 |
| **opponent** | op-(反) + pon(放) + -ent(人) | 反着放的人 | 对手、反对者 |
| **component** | com-(一起) + pon(放) + -ent | 放在一起的部分 | 组成部分、零件 |
| **composition** | compose + -ition | 组成的方式 | 组成、作文、作曲 |
| **proposal** | propose + -al | 提议的行为/内容 | 建议、提案 |
| **exposure** | expose + -ure | 暴露的状态 | 暴露、接触、曝光 |

## 例句（IELTS 场景）

- **position** — *The company holds a leading position in the global market.*
  - 写作 Task 2 / 阅读：take a position on / in a position to
- **purpose** — *The purpose of this essay is to examine the impact of social media.*
  - 写作 Task 2 开头段：the purpose of this essay/report
- **propose** — *Several solutions have been proposed to address the housing shortage.*
  - 写作核心动词：it has been proposed that / as proposed by
- **oppose** — *Many people opposed the construction of the new highway.*
  - 写作 Task 2 讨论分歧：be opposed to / strongly oppose
- **compose** — *The committee is composed of experts from various fields.*
  - 写作：be composed of = consist of（更正式）
- **expose** — *Exposure to diverse cultures broadens one's perspective.*
  - 写作/口语：be exposed to / exposure to
- **impose** — *The government imposed a tax on single-use plastics.*
  - 写作 Task 2 政策类话题核心词：impose a tax/ban/restriction on
- **suppose** — *It is widely supposed that the main cause of obesity is poor diet.*
  - 写作引出普遍观点：be supposed to / supposedly
- **deposit** — *A security deposit is usually required when renting an apartment.*
  - 听力 Section 1 租房场景
- **dispose** — *Proper disposal of electronic waste is an growing environmental concern.*
  - 写作环境话题：dispose of / waste disposal
- **postpone** — *The event had to be postponed due to unforeseen circumstances.*
  - 听力/口语：postpone = put off（更正式）
- **opponent** — *Opponents of the policy argue that it would stifle innovation.*
  - 写作 Task 2 讨论对立观点核心词
- **component** — *Renewable energy is a key component of a sustainable future.*
  - 写作：an essential / key / major component of

## 前缀拆解公式

```
[前缀] + pose/pos/pon

pro- 前   + pose → propose     提议（放在前面）
re-  后   + pose → repose      休息（放到后面→躺）
op-  反   + pose → oppose      反对（反着放）
com- 一起 + pose → compose     组成（放到一起）
ex-  出   + pose → expose      暴露（放出去）
im-  上   + pose → impose      强加（放在上面）
sup- 下   + pose → suppose     假设（放在下面当基础）
dis- 分开 + pose → dispose     处理（分开摆放）
de-  下   + posit → deposit    存放（放下）
post-后   + pone → postpone    推迟（放到后面）
op-  反   + pon  + ent → opponent 对手（反着放的人）
com- 一起 + pon  + ent → component 组件（放在一起的部件）
```

## 易混辨析

- **propose** vs **purpose**：propose = 提议（动词），purpose = 目的（名词）——拼写差一个位置，写作别写混
- **compose** vs **consist**：be composed of = consist of（可互换，前者更正式）
- **oppose** vs **object to**：oppose + noun/doing，object to + noun/doing（object 不需要 be 动词）
- **expose** vs **impose**：expose = 暴露（把覆盖物去掉），impose = 强加（把东西放上去）
- **dispose** vs **dispose of**：dispose sb to = 使某人倾向于，dispose of = 处理掉

## 相关词根

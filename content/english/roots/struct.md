# struct — 建造、堆叠

## 核心含义

拉丁语 _struere_ = to pile up, to build, to arrange。这个词根形态稳定，几乎不变体，是理解 IELTS 学术写作关键词的核心入口。

## 派生词网络

### Tier 1 — 雅思高频核心

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **structure** | struct(建造) + -ure(名词) | 建造出来的东西 | 结构、体系、建筑物 |
| **construct** | con-(一起) + struct(建造) | 建在一起 | 建造、构建 |
| **instruct** | in-(入) + struct(建造) | 把知识建进去 | 指示、教导 |
| **destroy** | de-(去除) + stroy(建造) | 把建好的拆掉 | 破坏、摧毁 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **obstruct** | ob-(阻碍) + struct(建造) | 建东西挡住 | 阻塞、妨碍 |
| **infrastructure** | infra-(下面) + structure | 下面的建筑 | 基础设施 |
| **instruction** | instruct + -ion | 教导的内容 | 说明、指令、教学 |
| **destruction** | destroy + -tion | 破坏的行为 | 摧毁、破坏 |
| **constructive** | construct + -ive | 建设性的 | 有建设性的 |
| **reconstruct** | re-(重新) + construct | 重建 | 重建、复原 |

## 例句（IELTS 场景）

- **structure** — *The essay lacks a clear structure, making the argument difficult to follow.*
  - 写作评分标准核心词：essay structure, sentence structure
- **construct** — *A new railway is being constructed to connect the two cities.*
  - 写作 Task 1 地图题/Task 2 基础设施话题
- **instruct** — *Participants were instructed to complete the survey within 30 minutes.*
  - 听力/阅读研究方法论：as instructed / follow instructions
- **destroy** — *Deforestation destroys natural habitats and threatens biodiversity.*
  - 写作 Task 2 环境话题高频动词
- **infrastructure** — *Investment in public infrastructure is essential for economic growth.*
  - 写作 Task 2 经济/城市话题核心词
- **constructive** — *Constructive feedback helps students identify areas for improvement.*
  - 口语 Part 3 / 写作：constructive criticism / constructive dialogue
- **obstruct** — *Parked vehicles obstruct the flow of traffic during peak hours.*
  - 写作描述问题：obstruct progress / justice / the view

## 前缀拆解公式

```
[前缀] + struct/stroy

con-   一起 + struct → construct      建造
in-    入   + struct → instruct       教导（把知识建进去）
de-    去除 + stroy  → destroy        破坏（拆掉）
ob-    阻碍 + struct → obstruct       阻塞
infra- 下面 + structure → infrastructure 基础设施
re-    重新 + construct → reconstruct  重建
```

## 易混辨析

- **construct** vs **build**：construct 更正式，build 更通用；学术写作中 construct 多用（construct a theory / argument / model）
- **instruct** ≠ **teach**：instruct 是给出具体指令，teach 是传授知识
- **destroy** ≠ **damage**：destroy 是完全毁灭，damage 是部分损坏

## 相关词根

- [[english/roots/duc|duc/duct]]（引导）→ produce, conduct — 建造（construct）和引导出（produce）都涉及"让某物成形"
- [[english/roots/port|port]]（携带）→ support — 支持（承载）是结构（structure）的功能

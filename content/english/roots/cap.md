# cap / cept / ceive — 拿、取

## 核心含义

拉丁语 _capere_ = to take, to seize, to grasp。这是英语中变体最多的词根之一，但所有变体都围绕同一个核心动作：**"拿"**。

三类变体规律：
- **cap-/capt-** → 名词/形容词（capture, capable, capacity）
- **cept-** → 名词（concept, except, accept → 名词为 -ception）
- **ceive-** → 动词（receive, perceive, conceive, deceive）

## 派生词网络

### Tier 1 — 雅思高频核心

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **accept** | ac-(=ad,向) + cept(拿) | 拿过来 → 接住 | 接受、同意 |
| **except** | ex-(出) + cept(拿) | 拿出来 → 排除 | 除了…之外 |
| **receive** | re-(回) + ceive(拿) | 拿回来 | 收到、接收 |
| **perceive** | per-(穿透) + ceive(拿) | 透彻地拿到 | 察觉、感知 |
| **concept** | con-(一起) + cept(拿) | 拿到一起 → 概括 | 概念、观念 |
| **capable** | cap(拿) + -able(能…的) | 能拿住的 | 有能力的 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **capture** | capt(拿) + -ure(名词) | 拿住的行为 | 捕获、俘获 |
| **conceive** | con-(一起) + ceive(拿) | 拿到一起 → 形成 | 构想、怀孕 |
| **deceive** | de-(离开) + ceive(拿) | 悄悄拿走 → 骗走 | 欺骗 |
| **anticipate** | anti-(前) + cip(拿) + -ate | 提前拿住 | 预期、预料 |
| **participate** | parti-(部分) + cip(拿) + -ate | 拿一部分 | 参与、参加 |
| **capacity** | cap(拿) + -acity(名词) | 能拿住的量 | 容量、能力 |
| **exception** | except + -ion | 拿出去的东西 | 例外 |

## 例句（IELTS 场景）

- **accept** — *Most scientists now accept that climate change is primarily caused by human activity.*
  - 写作表达共识：it is widely accepted that...
- **except** — *All participants completed the survey except for two who withdrew early.*
  - 写作 Task 1 描述数据：except for / with the exception of
- **receive** — *Students who received additional tutoring showed significant improvement.*
  - 写作/阅读：receive attention / support / criticism
- **perceive** — *How people perceive risk affects their decision-making.*
  - 写作 Task 2 讨论心理学/行为：be perceived as / perception of
- **concept** — *The concept of sustainable development has gained widespread acceptance.*
  - 写作/口语万能词：key concept / abstract concept
- **capable** — *Children are capable of learning multiple languages simultaneously.*
  - 口语/写作：be capable of doing
- **participate** — *Citizens should be encouraged to participate in local decision-making.*
  - 写作 Task 2 社会话题：participate in / active participation
- **anticipate** — *The project is anticipated to be completed by early 2027.*
  - 写作/阅读：it is anticipated that / as anticipated
- **deceive** — *Misleading advertisements may deceive consumers into buying unnecessary products.*
  - 阅读/写作消费者话题
- **capacity** — *The stadium has a seating capacity of 50,000.*
  - 写作 Task 1 / 听力：production capacity / at full capacity

## 前缀拆解公式

```
[前缀] + cap/cept/ceive

ac-   向   + cept → accept        接受（拿过来）
ex-   出   + cept → except        除了（拿出来）
re-   回   + ceive → receive      收到（拿回来）
per-  穿透 + ceive → perceive     感知（透彻拿到）
con-  一起 + ceive → conceive    构想（拿到一起形成）
de-   离开 + ceive → deceive     欺骗（悄悄拿走）
anti- 前   + cip  → anticipate    预期（提前拿住）
parti-部分 + cip  → participate   参与（拿一部分）
```

## 易混辨析

- **accept** vs **receive**：receive 是被动收到（收到礼物），accept 是主观接受（接受邀请）
- **concept** vs **conception**：concept 是概念本身，conception 是概念形成的过程（或"怀孕"）
- **deceive** vs **cheat**：deceive 是骗（误导信念），cheat 是作弊（违反规则）
- **except** vs **besides**：except 是排除（不包括），besides 是追加（还包括）

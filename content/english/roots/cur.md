# cur / curs / cours — 跑、流动

## 核心含义

拉丁语 _currere_ = to run, to flow。这个根在英语中延伸出三条线索：

1. **"跑" → 路径/行程** → course, curriculum, excursion
2. **"流动" → 现存的/通行中的** → current, currency, currently
3. **"跑到面前" → 发生/出现** → occur, occurrence, recur

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **course** | cours(e) ← cursus(跑的路径) | 跑的路径 | 课程、过程、路线 |
| **current** | curr(流动) + -ent(…的) | 正在流动的 | 当前的、水流/电流 |
| **occur** | oc-(=ob,向) + cur(跑) | 跑到面前来 | 发生、出现 |
| **currency** | curr(流动) + -ency(名词) | 流通之物 | 货币、通用 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **curriculum** | curri(跑) + culum(场所) | 跑完全程的东西 | 全部课程 |
| **excursion** | ex-(出) + curs(跑) + -ion | 跑出去 | 短途旅行、远足 |
| **occurrence** | occur + -ence(名词) | 发生的事 | 事件、发生的事情 |
| **recur** | re-(再) + cur(跑) | 再次跑来 | 再次发生、反复出现 |
| **precursor** | pre-(前) + curs(跑) + -or | 跑在前面的人/物 | 先驱、前兆 |
| **concurrent** | con-(一起) + curr(跑) + -ent | 一起跑的 | 同时发生的 |
| **discourse** | dis-(分开) + course(跑) | 跑来跑去 → 交流 | 话语、论述 |

## 例句（IELTS 场景）

- **course** — *The course covers topics ranging from basic grammar to academic writing.*
  - 听力/口语：enroll in a course, compulsory course, of course
- **current** — *The current situation demands immediate action from policymakers.*
  - 写作万能替换词：the current state of, current trends indicate
- **occur** — *Natural disasters occur with increasing frequency due to climate change.*
  - 写作 Task 2 描述现象：it never occurred to me that...
- **currency** — *A stable currency is essential for international trade and investment.*
  - 阅读/写作经济话题
- **curriculum** — *The school has redesigned its curriculum to include more practical skills.*
  - 写作 Task 2 教育话题核心词
- **occurrence** — *Such occurrences are rare but highlight the need for better safety measures.*
  - 写作描述事件：a common / rare / everyday occurrence
- **recur** — *The same issue recurs in many developing countries.*
  - 写作描述持续问题：a recurring theme / problem / pattern
- **concurrent** — *The two conferences will run concurrently next week.*
  - 阅读：concurrent with / simultaneously

## 前缀拆解公式

```
[前缀] + cur/curs/cours

oc-   向  + cur   → occur        发生（跑到面前）
re-   再  + cur   → recur        反复出现（再次跑来）
ex-   出  + curs  → excursion   短途旅行（跑出去）
pre-  前  + curs  → precursor   先驱（跑在前面的）
con-  一起 + curr → concurrent  同时发生的（一起跑的）
dis-  分开 + cours → discourse  话语（跑来跑去的交流）
```

## 易混辨析

- **course** vs **curriculum**：course 是一门课，curriculum 是全部课程体系
- **current** 做名词三种义项：水流、电流、潮流趋势 — 核心都是"流动"
- **occur** vs **happen**：occur 更正式，happen 更口语，写作中 occur 更优
- **currency** 不只是"货币"——还表示"通用性"（the idea has gained wide currency）

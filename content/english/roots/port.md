# port — 携带、运送

## 核心含义

拉丁语 _portare_ = to carry。这是英语中形态最稳定的词根——几乎不变体，识别度极高，非常适合初学者入门。

大部分派生词遵循模板：`[前缀] + port = [怎样]携带`

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **import** | im-(=in,入) + port(运) | 运进来 | 进口、输入 |
| **export** | ex-(出) + port(运) | 运出去 | 出口、输出 |
| **transport** | trans-(跨) + port(运) | 跨越运送 | 运输、交通 |
| **support** | sup-(=sub,下) + port(携带) | 从下面承载 | 支持、支撑 |
| **report** | re-(回) + port(携带) | 带回来 → 汇报 | 报告、报道 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **portable** | port(携带) + -able(可…的) | 可携带的 | 便携的 |
| **portfolio** | port(携带) + folio(纸张) | 携带纸张之物 | 作品集、投资组合 |
| **porter** | port(携带) + -er(人) | 搬运者 | 搬运工、门房 |
| **deport** | de-(离开) + port(运) | 运走 | 驱逐出境 |
| **passport** | pass(通过) + port(港口) | 通过港口 → 通行证 | 护照 |

## 例句（IELTS 场景）

- **import** — *The country imports over 90 percent of its consumer electronics.*
  - 写作 Task 1 描述进出口数据：imports exceeded exports
- **export** — *Australia's primary exports include iron ore, coal, and natural gas.*
  - 写作 Task 1 柱状图/表格高频
- **transport** — *Public transport reduces carbon emissions and eases traffic congestion.*
  - 写作 Task 2 环境/城市话题万能论点
- **support** — *The data supports the hypothesis that exercise improves cognitive function.*
  - 写作引入证据：evidence supports / this is supported by...
- **report** — *According to a recent UN report, deforestation rates have accelerated.*
  - 听力/阅读/写作通用：it is reported that / a report found that...
- **portable** — *Portable devices have transformed how we access information.*
  - 口语 Part 3 讨论科技
- **portfolio** — *A diverse investment portfolio reduces financial risk.*
  - 阅读 Section 3 经济/商业话题
- **passport** — *A passport serves as both an identity document and a travel permit.*
  - 听力 Section 1 旅行场景

## 前缀拆解公式

```
[方向前缀] + port

im-  入  + port → import      进口（运进来）
ex-  出  + port → export      出口（运出去）
trans-跨 + port → transport   运输（跨距离运）
re-  回  + port → report      报告（带回来）
sup- 下  + port → support     支持（从下面承载）
de-  离  + port → deport      驱逐（运走）
```

## 易混辨析

- **import / export** — 成对记忆，im 入 ex 出，几乎所有英语考试都考
- **support** 不只是"支持"——当动词还表示"养活、供养"（support a family），听力中常出现
- **report** 的固定搭配：report on（关于…的报告）、report to（向…汇报）

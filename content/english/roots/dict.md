# dict / dic — 说

## 核心含义

拉丁语 _dicere_ = to say, to speak, to declare。这个根进入英语后有两条路径：

1. **"说话"** → dictionary（关于词语的书）、dictate（口述让旁人写）
2. **"宣告/断言"** → predict（提前说）、verdict（陪审团的说法）

前缀决定方向，dict 决定"说"这件事本身。

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **predict** | pre-(前) + dict(说) | 提前说 | 预测、预言 |
| **dictate** | dict(说) + -ate(动词) | 口述让人写 | 口述、命令、支配 |
| **contradict** | contra-(对立) + dict(说) | 对着说 | 反驳、与…矛盾 |
| **indicate** | in-(向内) + dic(说) + -ate | 往里说 → 指出 | 表明、指示 |
| **verdict** | ver-(=true,真实) + dict(说) | 真相之说 | 裁决、定论 |
| **dictionary** | dict(说→词语) + -ion + -ary | 关于词语的书 | 词典 |

### Tier 2 — 重要扩展（认识即可）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **dedicate** | de-(完全) + dic(说) + -ate | 完全说出 → 献出 | 奉献、致力于 |
| **indication** | indicate + -ion | 表明的行为 | 迹象、指示 |
| **predictable** | predict + -able(可…的) | 可预测的 | 可预见的 |
| **contradiction** | contradict + -ion | 反驳的行为 | 矛盾 |
| **dictator** | dictate + -or(人) | 口述命令的人 | 独裁者 |
| **jurisdiction** | juris-(法律) + dict(说) + -ion | 法律的说话权 | 管辖权 |

## 例句（IELTS 场景）

- **predict** — *Scientists predict that global temperatures will rise by 2°C by 2050.*
  - 雅思写作 Task 1 / 2 高频：make a prediction, it is predicted that...
- **dictate** — *Market demand dictates the direction of technological innovation.*
  - 写作讨论因果：A dictates B（A 决定 B）
- **contradict** — *The evidence contradicts the widely held assumption that...*
  - 写作让步段核心动词
- **indicate** — *Recent studies indicate a significant decline in biodiversity.*
  - 写作引入数据：findings indicate that / as indicated by...
- **verdict** — *The jury reached a unanimous verdict after three days of deliberation.*
  - 听力 Section 3/4 法律话题高频
- **dictionary** — *Relying solely on a bilingual dictionary limits vocabulary acquisition.*
  - 口语 Part 3 讨论语言学习
- **dedicate** — *She has dedicated her career to renewable energy research.*
  - 写作/口语表达投入：be dedicated to + noun/-ing

## 前缀拆解公式

```
[方向前缀] + dict/dic + [后缀]

pre-  前  + dict → predict      预测（提前说）
contra-对  + dict → contradict   反驳（对着说）
in-   入  + dic  → indicate     指示（往里说）
ver-  真  + dict → verdict      裁决（真相之说）
de-   全  + dic  → dedicate     奉献（完全说出）
```

## 易混辨析

- **dictate** vs **indicate**：dictate 是"强加式地说"（command），indicate 是"指向式地说"（point out）
- **verdict** ≠ **sentence**：verdict 是"有罪/无罪"的裁定，sentence 是裁定后的"量刑"
- **dedicate** ≠ **devote**：语义几乎相同，dedicate 更正式，devote 更通用

# ple / pli / plen — 充满、填满

## 核心含义

拉丁语 *plere* = to fill, *plenus* = full。这个根覆盖雅思学术写作中最常出现的一批词：

1. **"满的/多的"** → plenty, plentiful, plenty
2. **"使完整 → 完成/补足"** → complete, complement, supplement, replenish
3. **"装进去 → 履行/执行"** → implement, accomplish
4. **"倒空 → 耗尽"** → deplete

## 派生词网络

### Tier 1 — 雅思高频核心

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **complete** | com-(加强) + ple(充满) + -te | 彻底装满 | 完整的、完成 |
| **implement** (v.) | im-(入) + ple(填满) + -ment | 填进去 | 实施、执行 |
| **plenty** | plen(满) + -ty | 充足的状态 | 丰富、大量 |
| **supply** | sup-(下) + ply(填满) | 从下面填满 | 供应、供给 |
| **deplete** | de-(去掉) + ple(填满) + -te | 倒空 | 耗尽、大量减少 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **complement** | com-(一起) + ple(装满) + -ment | 互相装满对方 | 补充、补充物 |
| **supplement** | sup-(下) + ple(填满) + -ment | 在下面再填 | 补充、增补 |
| **accomplish** | ac-(向) + com-(完全) + pli(装满) | 彻底装满 | 完成、实现 |
| **plentiful** | plent(满满) + -iful | 丰富的 | 大量的、充足的 |

## 例句（IELTS 场景）

- **complete** — *The project is expected to be completed by 2028.*
  - 写作 Task 1：complete a project / research / the process
- **implement** — *The government should implement stricter regulations to reduce pollution.*
  - 写作 Task 2 解决方案段万能动词
- **plenty** — *There are plenty of opportunities for those who seek them.*
  - 写作/口语：plenty of + 名词
- **supply** — *The supply of fresh water is becoming increasingly limited.*
  - 写作 Task 2 环境话题：supply and demand / water supply / energy supply
- **deplete** — *Natural resources are being rapidly depleted by industrial activities.*
  - 写作环境话题高频
- **complement** — *Online courses complement traditional classroom learning.*
  - 写作/口语：A complements B → A 与 B 互补
- **supplement** — *Many students take part-time jobs to supplement their income.*
  - 写作/口语：supplement one's income / a dietary supplement
- **accomplish** — *Without proper planning, it is difficult to accomplish anything significant.*
  - 写作：accomplish a goal / task / mission

## 前缀拆解公式

```
[方向] + ple/pli/plen

com- 完全 + plete   → complete     完成（彻底装满）
com- 完全 + pli     → accomplish   达成（彻底装满）
im-  入   + ple     → implement    执行（填进去执行）
de-  去掉 + ple     → deplete      耗尽（倒空）
sup- 下   + ply     → supply       供应（从下面填满）
sup- 下   + plement → supplement   补充（在下面再填）
```

## 易混辨析

- **complement** vs **compliment**：complement 是「互补」（e 在补），compliment 是「赞美」（i 在夸）——写作拼写陷阱
- **implement** vs **accomplish**：implement 强调"执行/落实"（实施计划），accomplish 强调"达成/成就"（完成目标）
- **supply** vs **provide**：supply 更正式、常与数量挂钩（supply of water），provide 更通用（provide services）
- **deplete** vs **exhaust**：deplete 强调数量大幅减少，exhaust 强调用光耗尽

# gen — 出生、种类、起源

## 核心含义

拉丁语 *gignere* = to beget, to produce; *genus* = race, kind, origin。词义分三条线：

1. **"出生/产生"** → generate, generation, gene, genetic
2. **"种类/类别"** → general, gender, generic
3. **"天生的品质"** → generous, genuine, genius, ingenious

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **generate** | gen(产生) + -ate(动词) | 使产生 | 产生、发（电）、生成 |
| **generation** | generate + -ion | 产生的过程/产物 | 产生、一代（人） |
| **general** | gen(种类) + -al(…的) | 关于种类的 | 一般的、普遍的、总的 |
| **generous** | gen(出生) + -ous(多…的) | 出身高贵的(慷慨的) | 慷慨的、大方的 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **genuine** | gen(出生) + -uine | 天生的 | 真正的、真诚的 |
| **genius** | gen(出生) + -ius | 天生的才能 | 天才、天赋 |
| **gene** | gen(出生) | 基因 | 基因 |
| **gender** | gen(种类) + -der | 种类 | 性别 |

| **ingenious** | in-(内) + gen(天赋) + -ious | 内有天赋的 | 巧妙的、精妙的 |

## 例句（IELTS 场景）

- **generate** — *The wind farm generates enough electricity to power 50,000 homes.*
  - 写作 Task 1 / 2：generate energy / electricity / revenue / jobs
- **generation** — *Each generation faces its own unique challenges.*
  - 写作 Task 2：the younger generation / the next generation / a generation gap
- **general** — *The general public is becoming more aware of environmental issues.*
  - 写作：in general / the general public / as a general rule
- **generous** — *The government provided generous funding for scientific research.*
  - 写作/口语：a generous amount / offer / donation
- **genuine** — *There is a genuine need for affordable housing in urban areas.*
  - 写作：a genuine concern / problem / interest
- **genetic** — *Genetic engineering raises both opportunities and ethical concerns.*
  - 阅读/写作科技话题
- **generalize** — *It is difficult to generalize about such a complex issue.*
  - 写作 Task 1 / 2：it is difficult to generalize / a generalization
- **ingenious** — *The engineers devised an ingenious solution to the problem.*
  - 阅读/写作：an ingenious solution / method / design

## 前缀拆解公式

```
[前缀] + gen/gener/genit

re-  再  + generate → regenerate  再生（再产生）
de-  下  + generate → degenerate  堕落（向下发展）
in-  内  + genius   → ingenious   精妙的（内心有天赋的）
```

## 易混辨析

- **generate** vs **produce**：generate 偏"生产能源/收入/创意"，produce 更通用
- **general** vs **common**：general = 普遍的（不是具体的），common = 常见的（频率高）
- **generous** vs **plentiful**：generous 形容人/数量的慷慨（a generous portion），plentiful 形容物产丰富（plentiful rainfall）
- **genuine** vs **real**：genuine 强调"不是假的/不是装的"（genuine emotion），real 更通用
- **ingenious** vs **genius**：ingenious 形容物（巧妙的），genius 形容人（天才的）

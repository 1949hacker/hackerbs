# scrib / script — 写

## 核心含义

拉丁语 _scribere_ = to write。这个根在 IELTS 写作 Task 1 和学术阅读中无处不在。

规律：
- **scribe** → 动词（describe, prescribe, subscribe）
- **script** → 名词（description, prescription, manuscript）

## 派生词网络

### Tier 1 — 雅思高频核心

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **describe** | de-(向下) + scribe(写) | 写下来 | 描述、形容 |
| **prescribe** | pre-(前) + scribe(写) | 事先写好 | 规定、开处方 |
| **subscribe** | sub-(下) + scribe(写) | 在下面写 → 签名同意 | 订阅、同意 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **description** | describe + -tion | 描述的行为/结果 | 描述、说明 |
| **prescription** | prescribe + -tion | 写好的规矩/药方 | 处方、规定 |
| **subscription** | subscribe + -tion | 签名的行为 | 订阅（费） |
| **manuscript** | manu-(手) + script(写) | 手写的 | 手稿、原稿 |
| **inscription** | in-(入) + script(写) + -ion | 刻写进去 | 铭文、题词 |
| **transcript** | trans-(跨) + script(写) | 转写 → 誊写 | 抄本、成绩单 |
| **postscript** | post-(后) + script(写) | 后写的 | 附言（P.S.） |

## 例句（IELTS 场景）

- **describe** — *The graph describes the changes in population over a 50-year period.*
  - 写作 Task 1 核心动词：describe / show / illustrate
- **prescribe** — *Doctors should not prescribe antibiotics unless absolutely necessary.*
  - 阅读/写作医疗话题：prescribe medication / treatment
- **subscribe** — *I subscribe to the view that education should be free for all.*
  - 写作表达立场：subscribe to a theory / belief / view
- **description** — *The job description outlines the key responsibilities and requirements.*
  - 听力 Section 1/2 求职场景
- **prescription** — *This medication is only available with a doctor's prescription.*
  - 听力 Section 1 医疗场景高频
- **manuscript** — *The original manuscript of the novel was discovered in the author's attic.*
  - 阅读 Section 3 文学/历史话题
- **transcript** — *Applicants are required to submit academic transcripts along with their application.*
  - 听力/阅读留学申请场景

## 前缀拆解公式

```
[前缀] + scribe/script

de-   下  + scribe → describe      描述（写下来）
pre-  前  + scribe → prescribe     规定（事先写好）
sub-  下  + scribe → subscribe    订阅（在下面签名）
in-   入  + script → inscription   铭文（刻进去）
manu- 手  + script → manuscript    手稿
trans-跨  + script → transcript    誊本（转写）
post- 后  + script → postscript    附言
```

## 易混辨析

- **describe** vs **prescribe**：describe 是描述已有事物，"prescribe"是规定应该做的事
- **prescribe** 两个核心义项：① 开处方（medical）② 规定（formal rules）
- **subscribe** 两个义项：① 订阅（subscribe to a channel）② 同意（subscribe to a view）

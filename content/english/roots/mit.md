# mit / miss — 发送、投掷

## 核心含义

拉丁语 _mittere_ = to send, to throw, to let go。这个根覆盖面极广——从"提交作业"到"发射导弹"都用它。

规律：
- **mit** → 动词原形（admit, commit, permit, submit）
- **miss** → 名词/形容词（mission, admission, dismissal）

## 派生词网络

### Tier 1 — 雅思高频核心

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **admit** | ad-(向) + mit(发送) | 发送进去 → 允许进入 | 承认、准许进入 |
| **commit** | com-(一起) + mit(发送) | 一起发送 → 托付 | 承诺、犯（罪）、投入 |
| **permit** | per-(通过) + mit(发送) | 放过去 | 允许、许可 |
| **submit** | sub-(下) + mit(发送) | 从下面送上去 | 提交、屈服 |
| **transmit** | trans-(跨) + mit(发送) | 跨越发送 | 传输、传播 |
| **mission** | miss(发送) + -ion | 被派出去的事 | 使命、任务 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **dismiss** | dis-(分开) + miss(送) | 送走 → 打发走 | 解雇、驳回、不予理会 |
| **omit** | o-(=ob,离开) + mit(送) | 送掉 → 漏掉 | 省略、遗漏 |
| **promise** | pro-(前) + mise(送) | 向前送出 → 保证 | 承诺、诺言 |
| **compromise** | com-(一起) + promise(承诺) | 互相承诺让步 | 妥协、折中 |
| **emission** | e-(出) + miss(送) + -ion | 送出去的东西 | 排放（物） |
| **admission** | admit + -ssion | 允许进入 | 准入、录取、入场费 |

## 例句（IELTS 场景）

- **admit** — *It must be admitted that technological progress has both benefits and drawbacks.*
  - 写作 Task 2 让步段：admittedly / it must be admitted that...
- **commit** — *The government has committed substantial funds to renewable energy projects.*
  - 写作表达投入：be committed to / make a commitment to
- **permit** — *Strict regulations do not permit the discharge of untreated waste into rivers.*
  - 写作讨论法规：permit someone to do / be permitted to
- **submit** — *Applicants must submit their documents before the deadline.*
  - 听力/阅读申请场景：submit an application / assignment
- **transmit** — *The disease is transmitted through contaminated water.*
  - 阅读 Section 3 健康/科学话题
- **mission** — *The organization's mission is to provide education to underprivileged children.*
  - 口语 Part 3 / 写作：mission statement, core mission
- **dismiss** — *The proposal was dismissed as impractical by the committee.*
  - 写作驳斥观点：dismiss an argument / idea
- **omission** — *The omission of key data undermines the credibility of the report.*
  - 写作 Task 1 评价数据完整性
- **compromise** — *A successful negotiation often requires compromise from both sides.*
  - 写作 Task 2 解决类：reach a compromise / without compromising quality

## 前缀拆解公式

```
[前缀] + mit/miss

ad-   向  + mit → admit       承认/准入（送进去）
com-  一起 + mit → commit     承诺/投入（一起托付）
per-  通过 + mit → permit     允许（放过去）
sub-  下  + mit → submit     提交（从下往上送）
trans-跨  + mit → transmit   传输（跨距离发送）
dis-  分开 + miss → dismiss   驳回（送走）
e-    出  + miss → emission  排放（送出去的东西）
o-    离  + mit → omit       省略（送掉 → 漏掉）
```

## 易混辨析

- **admit** 两个核心义项：① 承认（admit a mistake）② 准许进入（admit someone to a school）
- **commit** 的三个面：① commit to doing（承诺）② commit a crime（犯）③ be committed to（投入）
- **submit** vs **yield**：submit 是"提交/屈服于人"，yield 是"屈服/产出"
- **promise** vs **compromise**：promise（承诺），compromise（互相 promise → 妥协）

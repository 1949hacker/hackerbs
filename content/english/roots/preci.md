# preci — 价值、价格

## 核心含义

拉丁语 _pretium_ 的本义是"价格、价值"。进入英语后，这个词根沿着两条路径演变：

1. **经由法语进入** → precious, price, prize
2. **经由拉丁语直接借入** → appreciate, depreciate, appraise

## 派生词网络

### 核心派生

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **price** | pric(e) ← pretium | 价格 | 价格、代价 |
| **prize** | priz(e) ← price 变体 | 有价值之物 | 奖品、战利品 |
| **praise** | prais(e) ← pretiare（估价→称赞） | 给予价值 | 赞扬、赞美 |

### preci- / preti- 系列

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **precious** | preci + -ous（形容词后缀） | 有价值的 | 珍贵的、宝贵的 |
| **appreciate** | ap-(=ad-, 向) + preci + -ate | 向…赋予价值 | 欣赏、感激、增值 |
| **depreciate** | de-(向下) + preci + -ate | 降低价值 | 贬值、折旧、贬低 |
| **appraise** | ap-(=ad-) + praise（估价） | 去估价 | 评估、鉴定 |
| **appraisal** | appraise + -al（名词后缀） | 评估行为 | 评估、鉴定 |

### 扩展词汇

| 单词 | 说明 |
|------|------|
| **appreciation** | appreciate 的名词形式：欣赏、感激、升值 |
| **depreciation** | depreciate 的名词形式：贬值、折旧 |
| **appreciative** | 感激的、有欣赏力的 |
| **appreciable** | 可察觉的、相当可观的（大到可以"估价"的程度） |
| **semi-precious** | semi-(半) + precious → 半宝石的 |

## 反义词关系

- **appreciate**（升值） ↔ **depreciate**（贬值）
- **praise**（赞扬） ↔ **criticize**（批评） / **depreciate**（贬低）

## 易混辨析

- **appraise** vs **apprise**：前者是"评估"（与 price 同源），后者是"通知、告知"（与 preci 无关，来自法语 _apprendre_）
- **price** vs **prize** vs **praise**：三兄弟，都来自 pretium，但路径不同

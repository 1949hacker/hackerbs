# sum / sumpt — 拿取、花费

## 核心含义

拉丁语 *sumere* = to take, to assume, to consume。前缀决定"怎么拿"，sum/sumpt 决定"拿"本身。

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **assume** | as-(=ad,向) + sume(拿) | 拿过来 | 假设、假定、承担（责任） |
| **assumption** | assume + -tion | 拿过来的东西 | 假设、假定 |
| **consume** | con-(完全) + sume(拿) | 全部拿走 | 消费、消耗（时间/资源） |
| **consumption** | consume + -tion | 消费的行为 | 消费量、消耗 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **resume** (v.) | re-(回) + sume(拿) | 拿回来 | 重新开始、继续 |
| **resume** (n.) | 同上 |  拿回来的总结 | 简历（CV） |
| **presume** | pre-(前) + sume(拿) | 提前拿 | 假设（语气比 assume 更强） |

## 例句（IELTS 场景）

- **assume** — *It is generally assumed that economic growth leads to higher living standards.*
  - 写作 Task 2：it is assumed that / be widely assumed to...
- **assumption** — *The argument is based on the assumption that all children learn at the same pace.*
  - 写作 Task 2 批判观点：make an assumption / a flawed / incorrect assumption
- **consume** — *Households in developed countries consume far more energy than those in developing ones.*
  - 写作 Task 1 / 2
- **consumption** — *The consumption of fossil fuels must be reduced to combat climate change.*
  - 写作/阅读环境话题：energy / meat / alcohol consumption
- **resume** — *After a brief interruption, negotiations resumed the following week.*
  - 阅读/写作：resume talks / work / normal activities

## 前缀拆解公式

```
[前缀] + sume/sumpt

as-   向   + sume → assume     假设（拿过来作为前提）
con-  完全 + sume → consume    消耗（全部拿走）
re-   回   + sume → resume     继续（拿回来）
pre-  前   + sume → presume    假定（提前拿）
```

## 易混辨析

- **assume** vs **presume**：assume = 无根据或不确定的假设，presume = 有合理依据的推定（比较正式）
- **assume** vs **consume**：一个"拿→假设"，一个"拿→消耗"——前缀决定一切
- **resume** 做动词 vs 名词：动词读 /rɪˈzjuːm/（继续），名词读 /ˈrezəmeɪ/（简历）——听力考点
- **consumption** vs **consumption**：countable？不可数（the consumption of energy）

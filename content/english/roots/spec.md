# spec / spect / spic — 看

## 核心含义

拉丁语 _specere_ = to look, to see。这是英语中最能产的词根之一，变体多但规律清晰：

- **spec-** → 名词/形容词（spectacle, specific）
- **spect-** → 动词（inspect, respect, expect）
- **spic-** → 形容词/名词（conspicuous, suspicious）

## 派生词网络

### Tier 1 — 雅思高频核心（必须掌握）

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **expect** | ex-(出) + (s)pect(看) | 向外看 → 等待 | 期望、预计 |
| **respect** | re-(回) + spect(看) | 回头看 → 重视 | 尊重、方面 |
| **inspect** | in-(入) + spect(看) | 往里看 | 检查、视察 |
| **suspect** | sus-(=sub,下) + spect(看) | 下面看 → 猜测 | 怀疑、嫌疑犯 |
| **aspect** | a-(=ad,向) + spect(看) | 看向的一面 | 方面、层面 |
| **perspective** | per-(穿透) + spect(看) + -ive | 看透 → 视角 | 观点、视角 |
| **prospect** | pro-(前) + spect(看) | 向前看 | 前景、可能性 |

### Tier 2 — 重要扩展

| 单词 | 拆解 | 字面义 | 实际义 |
|------|------|--------|--------|
| **specify** | speci-(看→种类) + -fy(使) | 使看清楚 → 指明 | 明确说明、指定 |
| **specific** | speci-(看→区分) + -fic(做) | 区分开的 | 具体的、特定的 |
| **spectator** | spect(看) + -ator(人) | 看的人 | 观众 |
| **spectacle** | spect(看) + -acle(物) | 看的东西 | 景象、壮观场面 |
| **conspicuous** | con-(完全) + spic(看) + -uous | 完全看得见的 | 显眼的、引人注目的 |
| **speculate** | spec(看) + -ulate | 看 → 观察 → 推测 | 推测、投机 |

## 例句（IELTS 场景）

- **expect** — *Contrary to expectations, the policy led to a decline in productivity.*
  - 写作 Task 2：contrary to / beyond expectations, it is widely expected that...
- **respect** — *In many respects, renewable energy is now cheaper than fossil fuels.*
  - 写作：in this respect, with respect to（关于）
- **inspect** — *Regular inspections of industrial facilities are essential for environmental compliance.*
  - 听力 Section 3/4 环境/法规话题
- **suspect** — *Researchers suspect that microplastics may have long-term health implications.*
  - 写作引出不确定结论：it is suspected that...
- **aspect** — *One crucial aspect of urban planning is sustainable public transport.*
  - 写作 Task 2 万能结构词：a key aspect of...
- **perspective** — *From an economic perspective, the investment seems justified.*
  - 写作/口语表达立场：from my perspective, from a global perspective
- **prospect** — *The prospect of widespread automation raises concerns about employment.*
  - 写作 Task 2 讨论未来：the prospect of...
- **specify** — *The report specifies three main areas for improvement.*
  - 写作 Task 1 引用数据：as specified in the chart...
- **specific** — *Can you be more specific about the timeline?*
  - 口语 Part 3 高频追问

## 前缀拆解公式

```
[方向前缀] + spect

ex-   外  + spect → expect      期望（向外张望）
re-   回  + spect → respect     尊重（回头看）
in-   入  + spect → inspect     检查（往里看）
sus-  下  + spect → suspect     怀疑（下面偷看）
a-    向  + spect → aspect      方面（看向的）
pro-  前  + spect → prospect    前景（向前看）
circum-围 + spect → circumspect  谨慎的（环顾四周）
intro-内  + spect → introspect   内省（看自己里面）
```

## 易混辨析

- **respect** 的两个义项："尊重"（look back at with regard）和"方面"（in this respect）
- **perspective** vs **prospect**：perspective 是看问题的角度，prospect 是向前看的东西（未来）
- **speculate** vs **predict**：speculate 是无根据的推测，predict 是有依据的预测

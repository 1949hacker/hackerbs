# 常见前缀

前缀决定单词的**方向、否定、程度或时间**。掌握前缀后，生词的拆解准确率至少翻倍。

## 方向性前缀（最重要）

| 前缀 | 含义 | 示例 |
|------|------|------|
| **ad-** (ac-/af-/ag-/ap-/ar-/as-/at-) | 向、朝向 | admit, accept, attract, apply, arrive, assist, attend |
| **ex-** (e-/ef-) | 出、向外 | export, extract, eject, evade, emit |
| **in-** (im-/il-/ir-) | 入、向内 | import, include, inject, immigrate |
| **re-** | 回、再、重新 | return, reduce, revise, rebuild |
| **pro-** | 向前、赞成 | progress, produce, promote, propose |
| **pre-** | 在…之前 | predict, prepare, prevent, prescribe |
| **sub-** (suc-/suf-/sup-/sus-) | 在下面 | subway, submit, support, suspect, succeed |
| **trans-** | 跨越、穿过 | transport, transmit, transfer, transform |
| **inter-** | 在…之间 | international, interact, interrupt, interpret |
| **de-** | 向下、去除、离开 | decrease, destroy, depart, deduce |
| **dis-** (di-/dif-) | 分开、否定 | dismiss, distract, discover, differ |
| **se-** | 分开、隔离 | separate, select, secret |

## 否定前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| **un-** | 不、非 | unhappy, unable, unlikely, unusual |
| **in-** (im-/il-/ir-) | 不、非 | incorrect, impossible, illegal, irregular |
| **dis-** | 不、无、相反 | disagree, disappear, dishonest, disorder |
| **mis-** | 错误 | misunderstand, mislead, mistake |
| **non-** | 非、无 | nonsense, nonprofit, non-smoker |
| **anti-** | 反对、对抗 | antibiotic, antisocial, anticipate |
| **counter-** | 反对、相反 | contradict, counteract, counterpart |
| **mal-** | 坏的 | malfunction, malnutrition, maltreat |

## 程度与大小

| 前缀 | 含义 | 示例 |
|------|------|------|
| **super-** | 超、上 | supermarket, supervise, superficial |
| **over-** | 过度、在上 | overestimate, overlook, overcome |
| **under-** | 不足、在下 | underestimate, undergo, undergraduate |
| **semi-** | 半 | semicircle, semi-precious, semi-final |
| **multi-** | 多 | multiply, multimedia, multinational |
| **mini-** | 小 | minimum, minimize, minibus |

## 时间与顺序

| 前缀 | 含义 | 示例 |
|------|------|------|
| **pre-** | 在…之前 | preview, prehistoric, precaution |
| **post-** | 在…之后 | postpone, postscript, postgraduate |
| **fore-** | 预先、在前 | forecast, foresee, forehead |

## 数量前缀

| 前缀 | 含义 | 示例 |
|------|------|------|
| **uni-** / **mono-** | 一 | uniform, universe / monopoly, monotonous |
| **bi-** / **du-** | 二 | bicycle, bilingual / dual, duplicate |
| **tri-** | 三 | triangle, triple, trilogy |
| **cent-** | 百 | century, percent, centigrade |

## 同化规则速记

ad- 遇到不同辅音会同化：

```
ad- + t → at-   attend, attract
ad- + p → ap-   apply, appear
ad- + r → ar-   arrive, arrange
ad- + s → as-   assist, assign
ad- + g → ag-   aggressive, aggregate
ad- + c → ac-   accept, accompany
ad- + f → af-   affect, afford
```

同样的规则适用于 in-, sub-, con- 等同化前缀。
